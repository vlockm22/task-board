This is a Kanban-style project manager/task board application design with Next.js, Supabase, and TailwindCSS.

Functionality:
-Create custom tasks  

-Drag-and-drop tasks to completion state columns  

-Create and assign color-coded team members to specific tasks  

-Click on the task title to open a radial menu and add comments to tasks  

-Delete tasks by pressing the "X" in the top right corner of each task  

-Assign priority levels to task based on low, normal, or high priority
